# Vendored fonts

All vendored as latin-subset variable woff2 (local-first: no runtime CDN).

- **Lexend** (`Lexend-var.woff2`, wght 100–900) — © The Lexend Project Authors
  (https://github.com/googlefonts/lexend). SIL Open Font License 1.1.
  Chosen for legibility: large x-height, open spacing, distinct letterforms;
  directional reading-fluency evidence (Shaver-Troup).
- **JetBrains Mono** (`JetBrainsMono-var.woff2`, wght 100–800) — © 2020 The
  JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono).
  SIL Open Font License 1.1. Used for instrument data: counts, gauges, key hints.
- **Bricolage Grotesque** (`BricolageGrotesque-var.woff2`, opsz 12–96, wght 200–800) — © 2022
  The Bricolage Grotesque Project Authors (https://github.com/ateliertriay/bricolage).
  SIL Open Font License 1.1. Fontsource build 5.3.0. The Hearth display face (VISUAL-LANGUAGE
  gate G-B): Today and Clear headings, card titles, big numbers. The Library keeps Lexend.
